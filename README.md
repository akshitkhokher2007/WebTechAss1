## Objective

This assignment was about learning the basics of HTML and CSS. The goal was
to build a simple personal webpage using HTML tags for structure (headings,
paragraphs, lists, images, links, tables, forms) and then style it using
CSS (inline, internal, and external), and finally publish it with GitHub
Pages.

## Part 3 - Introduction to CSS

### Step 9 - Intro to CSS
Started adding styling to the page.

### Step 10 - Inline CSS
Changed the color of one paragraph directly with `style="color:blue;"`.

### Step 11 - Internal CSS
Added a `<style>` block inside `<head>` to set the body background color
and change the heading font.

### Step 12 - External CSS
Made a separate `style.css` file and linked it with
`<link rel="stylesheet" href="style.css">`, then moved most of my CSS rules
into it.

### Step 13 - CSS Syntax & Selectors
Used an element selector (`p {}`), a class selector (`.highlight {}`) and
an ID selector (`#main-heading {}`) with different colors/fonts to show the
difference between them.

### Step 14 - Classes vs IDs
Created a `.highlight` class used on more than one element, and a
`#main-heading` ID used only on my `<h1>`.

## Summary

Overall this assignment helped me understand the basic structure of a
webpage using HTML tags like headings, paragraphs, lists, tables, forms,
images and links. I also learned the three ways to add CSS (inline,
internal, external) and how selectors, the box model, positioning, sizing
units and floats work. It took me some time to get the positioning and
float parts to work properly, but in the end I managed to get everything
working and published on GitHub Pages.
